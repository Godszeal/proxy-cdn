# ZST CDN Proxy for Vercel

Deploy this as a standalone Next.js app on Vercel. It exposes:

- `GET /api/proxy?url=...` — fetch a target URL with hardened CDN headers and return it

## Deploy

1. Push this folder to a new GitHub repo
2. Import the repo in Vercel
3. Deploy
4. Give me the deployed URL, e.g. `https://zst-cdn-proxy.vercel.app`
